# Changelog

All notable user-facing changes are recorded here, following
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
`Unreleased` accumulates entries from feature PRs; on release day it is
renamed to the version number with the date, and the same text becomes the
GitHub Release notes.

## Unreleased

### Added

- SSM mixers: `MambaMixer` / `MambaBlock`, `Mamba2Mixer` / `Mamba2Block`,
  `Mamba3Mixer` / `Mamba3Block` (`spartan_torch.transformers.ssm`), with
  key-mappings to HF and `mamba-ssm` checkpoints (`compat/hf_mamba*.py`).
- `compat/dino_head.py`: key-mapping for DINO projection heads.
- `utils/lightning_progress.py`: overall training progress bars (tqdm/rich)
  for Lightning.
- Publish workflows: `publish.yml` (tag `v*` → PyPI via Trusted Publishing),
  `publish-test.yml` (manual dispatch → TestPyPI); Dependabot for
  GitHub Actions pins.
- CI matrix for `unit`: Python 3.11–3.14, plus non-blocking
  `unit-experimental` on 3.15.
- Attention benchmark split into prefill/decode modes (`just bench` runs
  both), with a decode Pareto plot.
- `ALiBiBias` layer (+ `alibi_slopes`) — extrapolation beyond train length.
- `spartan_torch.compat`: key-mapping timm ViT / torchvision ResNet-18 →
  primitives (no full networks in `src`; assemblies live in
  `tests/test_weight_parity.py`).
- Parity suite: `tests/test_weight_parity.py` (weights, gate `1e-5` /
  `0.99999`), `tests/test_sdpa_parity.py` (forward+backward vs `F.sdpa`);
  `RESULTS.md` is generated by `scripts/verify_pretrained.py`.
- Benchmark suite: `scripts/bench_attention.py` (warmup+median,
  `synchronize`, SPILL detection for WDDM paging), `bench/` CSV + Pareto
  plot.
- Experiments: `experiments/positional/` (sin/learned/RoPE/ALiBi +
  extrapolation), `experiments/norms/` (pre/post × LN/RMSNorm).
- `References` with arXiv-ids in every `src/` layer docstring.

### Changed

- `requires-python`: `>=3.13` → `>=3.11`.
- `MultiHeadAttention` / `TransformerBlock` / `CrossAttentionBlock`:
  `qkv_bias` / `out_bias` (loading biased QKV weights from timm/HF),
  `norm_mode="post"` in `TransformerBlock` (for ablations; default `pre`).
- CI: unit on PR (matrix), pretrained-parity on schedule/label, bench on
  dispatch (GPU runner). Pytest markers: `parity`, `pretrained`, `bench`.

### Fixed

- MAE: frequency sign in `_get_pos_embed` (`mae_model.py`), double gather of
  `pred` (decoder already returns the original order), `MAEDecoderHead`
  compares the raw prediction against the normalized target (as in the
  paper).
- Pairings: `SwiGLUFeedForward` ↔ HF `LlamaMLP` (strict-load, 1-to-1 keys),
  `RotaryPositionalEmbedding` ↔ HF rotary (including offset),
  `InvertedResidual` ↔ torchvision `InvertedResidual(e=6)` block-level
  (+ slice of `IMAGENET1K_V1`); `compat/hf_llama.py`.
- `ChunkedFeedForward` tests: `allclose` instead of exact equality
  (chunked GEMMs legitimately differ at ulp level across BLAS builds).
